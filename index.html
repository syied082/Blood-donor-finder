How the machine learning ranking works

Every donor card shows the predicted chance of a reply. A logistic regression model, trained in Python with scikit-learn, uses six facts: days since the last donation, past donations, distance, exact blood group match, night time request and 90-day eligibility. Available donors are ranked first, then by this chance.

Test results: accuracy 80.2%, precision 76.5%, recall 97.8%, ROC-AUC 0.84. The model was trained on synthetic data (4,000 examples) because no real donor history exists yet.
